BARDAHL — Очередь мастеров

Содержимое:
- index.html — приложение: вход по имени, выбор свободной позиции после входа, выбор услуг внутри приложения, общий круг и очередь.
- setup.sql — схема Supabase и серверные функции.
- icon.svg — жёлто-чёрная иконка BARDAHL с клетчатым флажком.
- manifest.webmanifest — настройки установки приложения на экран телефона.

Список мастеров (9): Мануйлов, Басаров, Ударцев, Омеленчук, Драгункин, Шатаев, Овчиников, Новолодский, Афанасьев.
Роль «Менеджер» доступна отдельно и не занимает место в очереди.
Ограничения на количество вошедших мастеров нет. После входа мастер сразу отображается в общей очереди, затем выбирает свободную позицию; до выбора он помечен «Без позиции». Число доступных позиций равно числу реально вошедших мастеров, занятые места недоступны. Если вошёл один мастер, в списке доступно только место №1.
Услуги выбираются после входа: АКПП, Антифриз, Халдекс. Число выбранных услуг задаёт число пропускаемых кругов.

Установка:
1. Сделайте резервную копию текущего index.html в GitHub.
2. В Supabase откройте SQL Editor и выполните setup.sql. ВАЖНО: скрипт очистит старые/заранее созданные записи очереди, чтобы очередь стала пустой и участники появлялись только после собственного нажатия «Войти». Скрипт создаёт queue_state и queue_members, функции очереди и ежедневный автоматический сброс в 21:00 по времени Казахстана (UTC+5). Для сброса используется pg_cron: если в SQL Editor появится сообщение, что pg_cron недоступен, включите расширение pg_cron в Supabase → Database → Extensions и выполните setup.sql повторно.
3. В GitHub-репозитории bardahl_queue замените index.html, добавьте icon.svg и manifest.webmanifest в корень репозитория.
4. Дождитесь публикации GitHub Pages, затем откройте сайт в Safari.
5. Для обновления ярлыка iPhone удалите старый ярлык и добавьте сайт на экран «Домой» повторно.

Примечания:
- Эта версия сохраняет общую очередь в Supabase и обновляет экран примерно каждые 7 секунд. Каждый день в 21:00 по времени Казахстана серверная задача удаляет всех мастеров из очереди и сбрасывает номер круга. Это работает, даже если сайт закрыт на всех телефонах, при условии что pg_cron включён и задача создана.
- Вход по имени без пароля — это удобный выбор участника, а не полноценная проверка личности. Не используйте публичный URL как защищённую систему контроля доступа.
- Перед запуском всем сервисом проверьте поведение пропусков кругов на тестовой очереди.
