BARDAHL — очередь мастеров (обновлённая версия)

Файлы:
- index.html — приложение
- setup.sql — схема и функции Supabase
- manifest.webmanifest, sw.js — установка PWA и кеш
- icon*.svg — иконки приложения

Важные изменения:
1. Можно выбрать любое свободное место №1–9 независимо от количества вошедших мастеров.
2. Занятые места нельзя выбрать; мастер может изменить свою позицию на свободную.
3. При выходе мастера остальные позиции НЕ перенумеровываются. История услуг сохраняется.
4. Таблица сортируется по выбранной позиции и показывает 6 кругов по горизонтали. Зелёная точка — в этом круге есть хотя бы одна выполненная услуга.
5. Панель АКПП / Антифриз / Халдекс находится отдельно внизу для вошедшего мастера.
6. Отметки и позиции хранятся в общей базе Supabase.

ПЕРЕД ПУБЛИКАЦИЕЙ: откройте Supabase → SQL Editor и выполните setup.sql целиком. Скрипт сохраняет существующую историю, но проверьте текущую конфигурацию базы перед запуском.
Затем загрузите все файлы в корень репозитория GitHub Pages.

Примечание: это приложение использует публичный ключ Supabase и открытые RPC-функции, как в исходной версии. Для реального публичного использования рекомендуется добавить авторизацию и ограничения доступа к изменяющим функциям.

Обновление v5: в ячейках таблицы теперь отображаются названия всех сохранённых услуг. Старые записи с номером круга больше 6 также видны в одном из шести столбцов. Service Worker cache version увеличена для принудительного обновления приложения.
