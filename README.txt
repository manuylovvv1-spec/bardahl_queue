BARDAHL — Очередь мастеров

Содержимое:
- index.html — приложение: вход по имени, выбор свободной позиции после входа, выбор услуг внутри приложения, общий круг и очередь.
- setup.sql — схема Supabase и серверные функции.
- icon.svg — жёлто-чёрная иконка BARDAHL с клетчатым флажком.
- manifest.webmanifest — настройки установки приложения на экран телефона.

Список мастеров: Мануйлов, Басаров, Ударцев, Омеленчук, Драгункин, Шатаев, Овчиников, Новолодский, Афанасьев.
Роль «Менеджер» доступна отдельно и не занимает место в очереди.
В очереди одновременно максимум 6 мастеров. После входа мастер сразу отображается в общей очереди, затем выбирает свободную позицию; до выбора он помечен «Без позиции».
Услуги выбираются после входа: АКПП, Антифриз, Халдекс. Число выбранных услуг задаёт число пропускаемых кругов.

Установка:
1. Сделайте резервную копию текущего index.html в GitHub.
2. В Supabase откройте SQL Editor и выполните setup.sql. Скрипт создаёт queue_state и queue_members и функции очереди.
3. В GitHub-репозитории bardahl_queue замените index.html, добавьте icon.svg и manifest.webmanifest в корень репозитория.
4. Дождитесь публикации GitHub Pages, затем откройте сайт в Safari.
5. Для обновления ярлыка iPhone удалите старый ярлык и добавьте сайт на экран «Домой» повторно.

Примечания:
- Эта версия сохраняет общую очередь в Supabase и обновляет экран примерно каждые 7 секунд.
- Вход по имени без пароля — это удобный выбор участника, а не полноценная проверка личности. Не используйте публичный URL как защищённую систему контроля доступа.
- Перед запуском всем сервисом проверьте поведение пропусков кругов на тестовой очереди.
