BARDAHL — ОЧЕРЕДЬ МАСТЕРОВ
===========================

Что внутри
- index.html — мобильное веб-приложение
- setup.sql — таблицы и политики базы данных
- После настройки публикуйте index.html как отдельный GitHub Pages сайт.

Функции
- Вход выбором имени без пароля.
- Общая очередь из 10 участников: Андрей, Дмитрий, Константин, Самат, Иван.О, Яков, Степан, Иван, Александр, Руководитель.
- Общие статусы завершения круга.
- Автоматическое начало следующего круга, когда все участники отметили завершение.
- Общая история работ/услуг.
- Обновление данных автоматически примерно каждые 12 секунд.

ВАЖНО
Сейчас вход без пароля — это удобный внутренний прототип, а не защищённая система идентификации.
Любой человек, у которого есть ссылка на сайт, может выбрать чужое имя. Для настоящей защиты
понадобятся персональные PIN-коды/авторизация и более строгие политики базы данных.

НАСТРОЙКА ОБЩЕЙ БАЗЫ SUPABASE
1. Откройте https://supabase.com и создайте бесплатный проект.
2. В проекте откройте SQL Editor → New query.
3. Откройте файл setup.sql, скопируйте весь текст в редактор и нажмите Run.
4. В Supabase откройте Project Settings → API (или Connect / API Keys).
5. Скопируйте Project URL и anon/public key. НИКОГДА не используйте service_role key в браузере.
6. Откройте index.html в редакторе и найдите:
   const SUPABASE_URL = "ВСТАВЬТЕ_SUPABASE_PROJECT_URL";
   const SUPABASE_ANON_KEY = "ВСТАВЬТЕ_SUPABASE_ANON_KEY";
   Вставьте свои URL и anon/public key между кавычками.
7. Создайте отдельный публичный GitHub-репозиторий, например bardahl-queue.
8. Загрузите index.html в корень репозитория.
9. GitHub → Settings → Pages → Deploy from a branch → main → /(root) → Save.
10. Откройте выданную HTTPS-ссылку в Safari на iPhone. Нажмите Поделиться → На экран «Домой».

Проверка
- Откройте сайт на двух телефонах.
- На обоих выберите разные имена.
- Отметьте завершение на одном телефоне: статус должен появиться на другом.
- Новый круг начинается автоматически, когда все десять участников завершат текущий.

Текущие ограничения
- Вход по имени не подтверждает личность.
- При одновременном нажатии «Завершил» двумя сотрудниками возможна редкая гонка переключения круга.
- Для реальной эксплуатации желательно добавить PIN-коды, аудит действий и атомарное переключение круга через функцию базы данных.
