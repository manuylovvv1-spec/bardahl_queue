BARDAHL Queue — обновление с панелями мастеров

Файлы:
- index.html — приложение
- setup.sql — таблицы и функции Supabase
- icon.svg, manifest.webmanifest — установка на экран телефона

Что добавлено:
- панель у каждого вошедшего мастера;
- отдельная отметка каждой выполненной услуги: АКПП, Антифриз, Халдекс;
- история услуг с возможностью исправить тип услуги/круг или удалить запись;
- отдельный ручной выбор числа пропускаемых кругов (0–20 в интерфейсе, база поддерживает 0–99);
- статистика услуг, завершённых кругов и пропусков;
- отметка услуги завершает ход мастера в текущем круге, если он не пропускает круги;
- менеджер видит панели и может редактировать записи;
- сохранена существующая общая очередь, вход по 9 фамилиям, выбор позиции и ежедневный сброс в 21:00 Казахстана при включённом pg_cron.

Установка:
1. Сохраните резервную копию текущего репозитория/файлов.
2. В Supabase откройте SQL Editor и выполните весь setup.sql. Скрипт не удаляет текущую очередь и историю услуг. Он обновляет функции и создаёт таблицы журнала.
3. В GitHub-репозитории bardahl_queue замените index.html, setup.sql (можно хранить в репозитории для удобства), icon.svg и manifest.webmanifest файлами из архива; сделайте commit.
4. После публикации откройте сайт и обновите страницу. На iPhone при старой версии может понадобиться закрыть вкладку и открыть заново.
5. Для автоматического сброса в 21:00 включите расширение pg_cron в Supabase Database → Extensions и повторно выполните setup.sql, если расширение было включено после первого запуска.

Важно:
- SQL необходимо выполнить в Supabase вручную; этот архив сам не меняет базу и не публикует сайт.
- Текущая система использует фамилии как идентификаторы и публичный publishable key. Ограничения управления не являются полноценной авторизацией пользователя; если приложение будет доступно посторонним, рекомендуется добавить Supabase Auth и права ролей.
